## A propos

Je conçois et je livre des applications web complètes : interface, API, base de données, conteneurisation et déploiement. Ce que j'aime, c'est mener un produit de la première maquette jusqu'au serveur qui tourne, plutôt que de m'arrêter à une seule couche.

- **Front** : React et Next.js au quotidien, Angular quand le projet le demande
- **Back** : Node.js / Bun côté TypeScript, Django et Django REST Framework côté Python
- **En entreprise** : C# et l'écosystème Microsoft (.NET, SQL Server) depuis 2023
- **Prod** : Docker, reverse proxy Caddy ou Nginx, intégration continue avec GitHub Actions
- **IA** : intégration de LLM dans des produits (API OpenAI, LangChain, LangGraph) et outillage autour de Claude Code

## Ma façon de travailler

- **De bout en bout** : je prends un sujet de la modélisation des données jusqu'au déploiement et aux sauvegardes.
- **Reproductible** : chaque projet se lance avec Docker Compose et se déploie par script ou par pipeline.
- **Vérifié** : tests automatisés (Vitest, Playwright) et intégration continue avant de livrer.
- **Sous Linux** : Arch Linux, Hyprland et Neovim comme environnement de tous les jours.
